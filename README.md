# Expense Tracker Dashboard

Responsive expense tracker using HTML, CSS, JavaScript, DOM, LocalStorage and Chart.js.

## Features
- Income/expense transactions
- Add, edit, delete
- Search and filters
- Automatic balance calculation
- LocalStorage persistence
- Category doughnut chart
- Monthly income vs expense bar chart
- Responsive layout

## Run
Open `index.html` in a modern browser. Chart.js is loaded from jsDelivr CDN.
